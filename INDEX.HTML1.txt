      <h2 id="heading-conceito">📌 1. O Conceito Oficial de Cyberbullying</h2>
      <p>
        O <strong>cyberbullying</strong> é definido oficialmente como a prática sistemática de violência psicológica, intimidação, humilhação, perseguição, constrangimento ou exposição não autorizada realizada por meio de redes digitais, aplicativos de mensagens, fóruns ou jogos online.
      </p>
      <p>
        Segundo a legislação brasileira (<strong>Lei nº 13.185/2015</strong> e atualizações da <strong>Lei nº 14.811/2024</strong>), caracteriza-se por condutas reiteradas efetuadas por meio da internet, redes sociais, aplicativos de mensagens instantâneas ou qualquer outro ambiente digital.
      </p>

      <div class="grid-2">
        <div class="stat-box">

          <span class="stat-number">24/7</span>

      <h2 id="heading-causas">🔍 2. Causas no Contexto de um Colégio de 1.500 Alunos</h2>
      <p>
        Com uma comunidade de 1.500 estudantes, criam-se centenas de grupos de conversa (WhatsApp, Telegram, Discord) por turma e por afinidade. As principais causas do surgimento do cyberbullying incluem:
      </p>
      <ul>
        <li><strong>Falsa sensação de anonimato:</strong> A ilusão de que perfis fakes ou mensagens apagadas não deixam rastros.</li>
        <li><strong>Efeito de "Manada" e Viralização:</strong> O desejo de ser aceito em grupos leva alunos a compartilhar figurinhas (stickers), memes e montagens pejorativas de colegas ou professores.</li>
        <li><strong>Distanciamento Emocional:</strong> A ausência do olhar presencial faz com que o agressor não mensure imediatamente a dor psicológica causada no outro.</li>
        <li><strong>Falta de Cidadania Digital:</strong> Desconhecimento dos limites entre brincadeira ("zoeira") e crime de injúria/difamação.</li>
      </ul>
    </section>

        <li><strong>Registro de Provas:</strong> Orientar as vítimas a <em>não apagar</em> as mensagens. Salvar capturas de tela (prints) com data e horário visíveis.</li>
        <li><strong>Oficinas de Uso Consciente:</strong> Aulas integradas sobre segurança da informação, respeito à privacidade e direito de imagem.</li>

      <div class="alert-card" role="alert">
        <h3>⚠️ Cyberbullying Agora é Crime no Código Penal!</h3>
        <p>
          Em janeiro de 2024, foi sancionada a <strong>Lei nº 14.811/2024</strong>, que incluiu o bullying e o cyberbullying no Código Penal Brasileiro (Artigo 146-A).
        </p>
      </div>

      <ul>
        <li><strong>Penalidade do Cyberbullying (Art. 146-A, Parágrafo Único):</strong> Se a conduta é realizada em ambiente virtual (redes sociais, jogos, aplicativos), a pena é de <strong>reclusão de 2 a 4 anos e multa</strong>.</li>
        <li><strong>Responsabilidade de Menores de Idade:</strong> Quando praticado por crianças ou adolescentes (menores de 18 anos), o ato é enquadrado como <strong>Ato Infracional</strong> análogo ao crime, sujeitando o jovem a medidas socioeducativas previstas pelo ECA (Estatuto da Criança e do Adolescente), como prestação de serviços à comunidade ou internação em casos graves.</li>
        <li><strong>Responsabilização dos Pais:</strong> Os pais ou responsáveis legais podem ser condenados na esfera cível a pagar indenizações por danos morais causados pelos filhos.</li>
      </ul>

  <script>
    // 1. Controle de Tamanho de Fonte
    let fontScale = 100;
    
    function adjustFont(val) {
      fontScale += val * 10;
      if (fontScale < 80) fontScale = 80;
      if (fontScale > 160) fontScale = 160;
      document.documentElement.style.fontSize = fontScale + '%';
    }

    function resetFont() {
      fontScale = 100;
      document.documentElement.style.fontSize = '100%';
    }

    // 2. Alternar Alto Contraste
    function toggleContrast() {
      document.body.classList.toggle('high-contrast');
    }

    // 3. Fonte Legível (Dislexia)
    function toggleDyslexic() {
      document.body.classList.toggle('dyslexic-font');
    }

    // 4. Leitor de Tela Sintetizador de Voz (Web Speech API)
    let isSpeaking = false;
    
    function speakContent() {
      const btn = document.getElementById('btn-read');

      if (!('speechSynthesis' in window)) {
        alert('Seu navegador não suporta a leitura de voz automática.');
        return;
      }

      if (isSpeaking) {
        window.speechSynthesis.cancel();
        isSpeaking = false;
        btn.innerText = '🔊 Ouvir Página';
      } else {
        const textToRead = document.getElementById('conteudo-principal').innerText;
        const utterance = new SpeechSynthesisUtterance(textToRead);
        utterance.lang = 'pt-BR';
        utterance.rate = 1.0;

        utterance.onend = function() {
          isSpeaking = false;
          btn.innerText = '🔊 Ouvir Página';
        };

        window.speechSynthesis.speak(utterance);
        isSpeaking = true;
        btn.innerText = '⏹️ Parar Leitura';
      }
    }
  </script>
